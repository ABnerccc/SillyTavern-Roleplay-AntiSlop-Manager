# Roleplay Anti-Slop Manager

适用于 SillyTavern 的中文角色扮演前端扩展。通过可编辑提示词、文风示例和近期重复检测，减少人物反应、对白和叙事里的套话。统计在浏览器内运行，扩展仅向酒馆原本的生成请求添加指导文字。它不会修改历史消息、清洗上下文、修改角色卡或调用额外的 AI API。

## 安装

要求 **SillyTavern 1.19.1 或更新版本**和当前版本的 Chrome、Edge、Firefox 或 Safari。扩展本身无需安装依赖或构建。

1. **ZIP 安装**。将 ZIP 内的 `SillyTavern-Roleplay-AntiSlop-Manager` 文件夹放到酒馆的 `data/<用户目录>/extensions/` 下。单人默认配置的用户目录通常是 `default-user`。`manifest.json` 必须直接位于扩展文件夹内。若使用非默认数据目录，请在实际数据目录下查找对应用户的 `extensions/`。
2. **GitHub 安装**。如果酒馆服务器上的 Git 已获该私有仓库的读取权限，可在「扩展 → 安装扩展」输入仓库地址 `https://github.com/ABnerccc/SillyTavern-Roleplay-AntiSlop-Manager`。私有仓库读取权限不足时使用 ZIP 安装。
3. 刷新酒馆，在「扩展」里展开 **Roleplay Anti-Slop Manager**。需要为同一台服务器上的全部用户安装时，可把同一个扩展文件夹放到 `public/scripts/extensions/third-party/`。两个位置任选其一。

从 1.0.0 升级时，更新同一扩展目录并刷新酒馆。已有预设、模块开关和自定义正反例会在读取时迁移。也可导入 1.0.0 导出的 JSON。

## 使用

- **组合预设**提供「均衡」「轻量」「全部模块」三套起始配置。修改实时保存到当前组合。用「另存为新预设」复制整套设置，原组合保留。酒馆设置会持久化这些预设，切换时无需刷新页面。
- **提示词模块**按原综合排名初始化。每项可独立开关、改名、编辑、调整位置或顺序，也可新增、复制、删除。展开「高质量文风示例」的编辑区，可新增或删除条目、编辑名称和内容、选择正例或反例，并逐条启停。示例作为提示词文字注入。
- **注入位置**可选择故事提示词前、故事提示词后或聊天内深度。模块可继承预设的位置，也可覆盖。同一个位置的模块按列表顺序合并。末端强化与动态提醒使用聊天深度 0，强化文字在该扩展的深度 0 提示块内排在最后。
- **注入预览**按位置显示扩展将注册的文本、长度和预计额外输入 Token。总长度上限按 UTF-16 字符单位计数，大部分中文字符计 1 个单位，部分生僻字和表情计 2 个单位。优先为末端强化预留空间，再按列表处理模块。超长内容整段跳过并列出名称，文风示例逐条判断是否能容纳。最终请求受酒馆的模板、宏、上下文预算和后端消息格式影响。
- **导入、导出 JSON**包含全部预设、示例、全局开关和消耗档位。导入校验通过后会提示确认替换。配置文件只包含用户设置。关闭面板里的「启用扩展」会清除当前注入，保留设置。

### 全局消耗控制

拖动 **1–99** 滑块即可应用档位，切换组合预设时保留当前档位。1 档仅开放排名第一的「角色自主性」。滑块逐级开放后续模块，末端强化从 6 档开启，动态词库和句式从 43、63 档开启。99 档开启当前预设的全部模块和三项技术功能，仍遵守总字符上限、样本阈值、动态限额和每条文风示例的独立开关。自建模块在自动模式下从 99 档开放。

自动档位上仍可单独关闭当前档位允许的模块或技术功能。重新拉到 99 会清除自动模式下的手动关闭项。点击「恢复预设开关」回到预设原有的手动组合。每个预设单独保存模块编辑和文风示例。

预计 Token 按实际进入本次预览的提示词计算，主要以约 1.2 Token/汉字、约 4 个连续拉丁字母或数字/Token 和每个注入块的少量格式开销估算。估算在浏览器内运行，实际值随模型分词方式而变。 [SillyTavern 分词器说明](https://docs.sillytavern.app/usage/prompts/tokenizer/)

### 动态统计规则

- 样本为当前聊天显示中的最近 **N 条含中文的角色回复**，每条最多读取开头 6000 个 UTF-16 字符单位。同一条消息只读当前选中的回复版本。过滤玩家消息、系统消息、代码围栏、链接和思考标签内容。窗口默认为 12 条，只按命中的不同回复数判断是否达到阈值，默认至少 2 条。同一条消息多次出现不会代替多轮复现。
- 常见功能词、当前人物名、群聊成员名、消息署名及手填别名从候选中排除。白名单优先于黑名单，对包含白名单词的候选短语同样有效。黑白名单支持 1–16 个汉字的词条，可换行或用逗号分隔。未署名的角色别称可在「额外角色名和别名」补充。
- 普通高频词只显示在统计里，可手动加入黑名单。内置八股词与符合叙事短语规则的重复表达进入本次词库。黑名单可在词尚未出现时生效。样本离开窗口后，自动发现的词会随重新统计退出词库。
- 最近一轮权重为 1。再旧一轮乘一次衰减系数，每条回复对一个词或结构最多贡献 3 次加权命中。句式检测先去掉常见引号内的对白，再用固定规则寻找否定后转折、仿佛式描写、三连短句等结构。注入的是词条或预写的短提醒。动态字符上限和条数上限由词条和句式共享，可设为 0。

## API 与验证

扩展通过 `SillyTavern.getContext()` 访问设置、事件和 `setExtensionPrompt()`。监听 `GENERATION_AFTER_COMMANDS`，在酒馆组装请求前更新稳定的注入键。设置变更会重算预览，重复生成不会追加同一注入块。`GENERATE_AFTER_DATA` 清理演练请求注册项，生成结束、停止、切换聊天或在酒馆中停用扩展时清理本扩展的键。开启状态下，正常生成、重生成、切换生成和续写可获得提示。静默生成和代写玩家模式跳过注入。

核对基准是官方 1.19.1 的 [扩展指南](https://docs.sillytavern.app/for-contributors/writing-extensions/)、[`getContext` 导出](https://github.com/SillyTavern/SillyTavern/blob/1.19.1/public/scripts/st-context.js)、[生成及文本补全流程](https://github.com/SillyTavern/SillyTavern/blob/1.19.1/public/script.js)与 [Chat Completion 组装流程](https://github.com/SillyTavern/SillyTavern/blob/1.19.1/public/scripts/openai.js)。Text Completion 自定义故事模板须保留酒馆相应的 `{{anchorBefore}}`、`{{anchorAfter}}` 注入点。反八股效果会随模型和预设变化。

使用 Node.js 22 或更高版本运行测试，无需下载测试依赖。

```sh
npm test
```

自动测试涵盖 22 个模块及默认状态、配置往返、中文动态统计、角色专名和白名单、跨轮权重、句式筛查、注入位置和字符上限、去重、不同生成事件的清理、切换聊天及重新载入配置。宿主单测使用模拟环境和冻结的聊天数据。

1.0.0 的 10 项自动测试已通过。另在独立的官方 1.19.1 实例中安装 ZIP，用模拟聊天对 Chat Completion 和 Text Completion 执行演练，检查了实际组装的提示词、位置调整、末端顺序、重复注入、代写模式跳过、全局关闭以及演练结束后的清理。演练过程未发起模型补全，也未测量模型生成的文风改善程度。

1.1.0 的 14 项自动测试已通过。在同版本酒馆实例中复核了 1 档和 99 档、预计 Token 联动、示例的新增和删除，以及两个补全模式下的示例单独停用。两种模式均通过演练。

在酒馆里复核时，可展开注入预览后切换预设、移动模块、开关末端强化并检查各区块。用含重复表达的中文聊天查看统计，再通过酒馆的 Prompt Inspector 或提示词条目观察实际请求，确认相同模块只出现一次。关闭扩展后再生成一轮，检查扩展提示已消失。
